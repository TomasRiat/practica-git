# Práctica de Git: tu primer pull request

Repositorio de práctica del libro **«Git y GitHub desde cero»** de [Tienda del Estudiante](https://tiendadelestudiante.com).

Sirve para probar el camino completo de una contribución a un proyecto ajeno:

1. Hacé un **fork** de este repositorio (botón **Fork** > **Create fork**).
2. Cloná **tu fork**, creá una rama y sumá tu nombre al final de [`participantes.md`](participantes.md).
3. Subí la rama a tu fork y abrí un **pull request** contra este repositorio.

Los pasos completos, con los comandos y lo que tenés que ver en cada uno, están en el capítulo «Colaborar en GitHub» del libro.

Por favor, sumá solo tu nombre (o un apodo) y tu ciudad. Nada de datos personales como mail o teléfono: este repositorio es público.
